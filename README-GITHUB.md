# Nova Service – GitHub Pages

1. Alle Dateien dieses Ordners in ein GitHub-Repository laden.
2. In GitHub unter **Settings → Pages** die Veröffentlichung über den gewünschten Branch aktivieren.
3. Vor dem Livegang die Platzhalter in `impressum.html` und `datenschutz.html` prüfen/ergänzen.
4. In `index.html` die E-Mail-Adresse ergänzen.
5. Danach die GitHub-Pages-Adresse aufrufen.

Die Seite ist responsiv und für Smartphone/Desktop ausgelegt.
